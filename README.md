# 状态栏扩展（st-status-bar）

SillyTavern 第三方扩展 —— 让 AI 在每次回复末尾生成**可折叠的角色状态栏**，追踪当前在场角色与用户角色的实时状态。

样式与机制参考 PiuPiu 酱的状态栏方案（`<details>` 原生折叠 + 在场判定 + 双模板），并加入主题定制与条目自定义。

## ✨ 功能特性

- **在场角色状态栏**：AI 分析最近对话，只对**当前在场**的角色生成状态栏（说话 / 被提及 / 被暗示在场的角色）；不在场（其他房间 / 睡着 / 已离开 / 未登场）的角色绝不生成
- **用户状态栏**：为你扮演的角色单独生成一个状态栏，固定显示在第一个；只整理你消息里**明确写出**的信息，未明确的项填「未明确」，不替你脑补
- **原生折叠**：每个状态栏用 `<details>` 包裹，默认折叠，点击展开。折叠态显示「名字 · 年龄」，展开态显示各项状态
- **条目完全自定义**：状态条目（地点 / 情绪 / 穿着 / 身体 / 想法 …）可增删、排序，每条可写**书写规则**（告诉模型这条怎么展示、怎么描述）
- **主题定制**：主色自定义（边框 / 标题文字 / 分隔线 / 阴影统一由主色派生），边框样式（实线 / 虚线 / 点线）、粗细、圆角均可调；默认 PiuPiu 粉 `#ff6b9d`
- **不污染正文**：状态栏是隐形 UI 元素，正文叙事不受影响
- **不干扰其他生成**：安静生成（生图提示词 / 摘要等）不会注入状态栏指令

## 📥 安装

SillyTavern → 扩展（拼图图标）→ **安装扩展** → 输入：

```
YunLin000/st-status-bar
```

安装后刷新页面，在扩展列表里启用「状态栏扩展」。

## 🚀 使用

1. 扩展面板找到 **📊 状态栏扩展**，打开**总开关「启用状态栏」**
2. 正常聊天即可 —— AI 每次回复末尾会追加可折叠状态栏
3. 想调整样式 / 条目，在同面板里改（见下）

## ⚙️ 设置

### 主题定制
- **主色**：7 个预设色块（默认粉 / 青黛 / 竹青 / 鎏金 / 藕荷 / 朱砂 / 天青）+ 自定义取色器
- **边框样式**：实线 / 虚线 / 点线
- **粗细 / 圆角**：滑条调节
- **恢复默认**：一键回到 PiuPiu 原始样式（粉 · 实线 · 1px · 12px）

### 角色状态栏 / 用户状态栏
- **折叠栏标题模板**：`{{name}}` = 角色名，`{{age}}` = 年龄
- **状态条目**：每条含「条目名」+「书写规则」；可上移 / 下移 / 删除 / 添加
  - 例：条目名「想法」，规则写「角色当下的内心想法，第三人称，不超过20字」

## 🔧 工作原理

1. 扩展通过 `generate_interceptor` 在每次生成前，把**状态栏协议**注入到对话最深层
2. 协议要求 AI 在回复末尾输出 `<details><summary>名字 · 年龄</summary><div class="details-content">…</div></details>`
3. SillyTavern 的消息渲染管线原生支持 `<details>`，浏览器自动实现折叠交互
4. 扩展动态注入主题 CSS（`<style id="st-status-bar-theme">`），所有状态栏卡片跟随主题

## 📄 说明

- 需要 SillyTavern 1.12.0+
- 状态栏内容会占用少量 token（每轮生成）
- 与生图类扩展（如 yunhui-image-gen）互不冲突，状态栏在正文末尾、生图图片之前
